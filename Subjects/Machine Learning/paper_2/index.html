Hebbian Learning

Application of Hebb's Rule · Boolean Functions

one tiny neuron against sixteen logic functions ♡

01

Objective

The objective of this experiment is to consider the 16 Boolean functions that can be constructed from two variables and verify which of them can be represented by a neural network using Hebbian learning.

Using bipolar representation, Hebb's Rule is applied to each function in order to determine the corresponding weights and evaluate whether the resulting neuron can correctly reproduce its expected outputs.

02

Bipolar Representation

Instead of representing logical values as 0 and 1, the experiment uses bipolar values:

FALSE -1
TRUE +1
03

Hebb's Rule

For each input pattern, the neuron updates its weights according to the input values and the expected output.

WEIGHT UPDATE

w₀ = w₀ + y

w₁ = w₁ + x₁y

w₂ = w₂ + x₂y

IN SHORT

Each training example contributes to the final weights. The input values and expected output determine how each weight is updated.

see example → adjust weights → repeat

04

Implementation

The experiment was implemented in C. The program stores all 16 possible Boolean functions, applies Hebbian learning to each one, calculates the resulting weights and then tests the neuron against all four input combinations.

16 functions → Hebbian learning → weights → test
AUTOMATED PROCESS

The same training and testing process is automatically applied to every Boolean function rather than calculating each function manually.

06

The Exceptions

XOR and XNOR were the only functions that were not completely represented by the neuron. Both obtained only two correct outputs out of four.

FUNCTION 06

XOR

Weights: w₀ = 0, w₁ = 0, w₂ = 0

Accuracy: 2 / 4

FUNCTION 09

XNOR

Weights: w₀ = 0, w₁ = 0, w₂ = 0

Accuracy: 2 / 4

WHY?

XOR and XNOR are not linearly separable. Their two output classes cannot be separated using a single linear decision boundary.

the neuron isn't stupid — we're asking one line to do the impossible ♡

07

Conclusion

The experiment demonstrates that Hebbian learning can determine suitable weights for 14 of the 16 Boolean functions when bipolar representation is used.

XOR and XNOR remain the two exceptions, showing a limitation of representing these functions with this single-neuron model.

MAIN RESULT

14 functions learned. 2 exceptions.
